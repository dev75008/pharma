# Sources et licences
Le registre contient les huit références principales demandées. La BDPM est utilisée pour 13 synthèses documentaires originales très brèves avec lien, rubrique RCP et dates par champ ; aucune monographie complète n’est reproduite. Les autres références restent des liens. Aucun connecteur automatique, téléchargement massif ni scraping n’est effectué.
Les [mentions légales BDPM](https://base-donnees-publique.medicaments.gouv.fr/mentions-legales) ont été consultées le 12 octobre 2026 : elles identifient l’éditeur mais n’établissent pas à elles seules une licence de réutilisation automatisée. Aucune licence de dataset, API, quota ou compatibilité CORS n’est déclarée vérifiée. Les courtes synthèses ne constituent pas une redistribution de la base. Une intégration automatisée devra être vérifiée séparément en phase 7.
Avant tout adaptateur : consigner la documentation officielle, la licence, les modalités de téléchargement, quotas, règles de cache et tests CORS datés. En cas de restriction, conserver des liens ou autoriser un import manuel légal. Aucun scraping ni contournement.
Chaque futur champ médical doit conserver source, URL, consultation, mise à jour connue, niveau de vérification et disponibilité. Donnée absente : « À documenter ».
Sources complémentaires à étudier : PubMed/NCBI, RCSB, SwissADME, SwissTargetPrediction, ChemSpider, HAS, collèges, Angers ; BANM/SFPC à identifier précisément. Pilly et Katzung : références bibliographiques, sans reproduction non autorisée.
Les dépendances ont leurs propres licences, consultables dans leurs paquets. Le projet n’accorde aucune licence sur le contenu des sources tierces.
