# Limites pédagogiques et stockage
MEDREVISION est destiné à l’apprentissage personnel et non au diagnostic ou à la prescription. Aucun contenu scientifique n’est fourni dans cette phase. La mention DFASM2 indique le public visé, pas une validation universitaire.
Les exemples futurs non validés seront explicitement marqués comme démonstration. Les cas concerneront uniquement des patients fictifs. Les scores locaux ne prétendront pas reproduire un barème national.
Les préférences sont conservées uniquement dans le navigateur via IndexedDB. Réinitialisation, mode privé ou restrictions de stockage peuvent les supprimer. Aucune synchronisation entre appareils. L’import/export versionné arrive avec les données de progression.
La coquille PWA est précachée après une première visite de production. Aucune page scientifique externe n’est garantie hors ligne. Le manifeste SVG n’offre pas à lui seul une installation identique sur tous les systèmes.
Accessibilité : langue, titres, landmarks, lien d’évitement, focus visible, champs étiquetés, navigation clavier et réduction des animations. Un audit WCAG 2.2 AA complet reste nécessaire avant d’affirmer la conformité.
